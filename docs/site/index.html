FastApiClient

A light and fast REST API client for Linux. Send with Ctrl+Enter.

GitHub · Releases

Early version. Tested on Linux Mint Cinnamon.

What it does

Written in Rust with Slint, software rendering only, no async runtime.

Light and fastSmall binary, little memory, starts quickly.
Projects and foldersNested folders; headers and auth are inherited down to each request.
Environments and variablesType {{ to pick a variable; ready-made functions like dates.
Request chainingTake a token from another request's response; it is fetched when missing or expired.
Response panelJSON and XML beautify, search, headers, and the request actually sent.
Insomnia importBring in Insomnia v5 exports, or export your projects as JSON.

Install with Flatpak (updates itself)

This remote keeps FastApiClient updated with flatpak update and your software centre:

flatpak remote-add --system --if-not-exists fastapiclient https://evandro777.github.io/FastApiClient/fastapiclient.flatpakrepo
flatpak install --system fastapiclient io.github.evandro777.FastApiClient

Use --system: Linux Mint's Update Manager only looks at system-wide Flatpaks. The runtime comes from Flathub. The remote is GPG-signed, but the key lives in the source repository, so it is only as trustworthy as that.

Or the AppImage

Download FastApiClient-<version>-x86_64.AppImage from the latest release, chmod +x it and run it. It uses the fontconfig, xkbcommon and X11 libraries already on your system, and carries update information, so AppImageUpdate, Gear Lever or AppManager download only what changed.

Run one of the two, not both: they use different data folders.
